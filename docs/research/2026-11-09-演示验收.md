## 本次修复

1. 标题别名用于定位完整标题，章节不再从短别名中间开始。
2. 引文核验使用去掉来源注释、图片占位和 Markdown 标记的正文视图；原始 Markdown 与 PDF 保留。
3. 无表格行不再自动等于结构失败；空披露的期间、范围无法确认时也不能绕过校验得到 MATCH。
4. 支持同一句报告期间省略重复年份；跨年歧义与非法日期不自动补齐。
5. 表级披露范围使用稳定字段。行业规则明确：该市场整体组合为 all，指数/积极子表分别保留，确实不明仍为 unknown。
6. 股票明细按招募说明书定义核对目标集合。招书前 N 名、报告全量时，只比较招书列出的证券；报告多出的证券不生成单侧差异。报告披露范围不足以覆盖招书目标时仍待复核。
7. 保留披露核验失败原因；支持引用坐标与模块跳转。同页重复句子只有在章节标题能唯一消歧时才框选，否则保留页码与原文。
8. 概要补充来源的状态、理由与最终选定来源同步；年度费用缺少可比依据时不强行比较。
9. 模型 JSON 格式损坏时，仅恢复已完整解码且有稳定 item_id 的条目，损坏/未返回条目仍待后续处理；原始响应留痕。
10. 任务记录加入 owner_pid，其他共用任务目录的热重载服务不会再把仍在执行的任务误标中断。
